# Avto — мобильное приложение

Expo (SDK 58) + expo-router. Использует тот же API и тот же клиент `@avto/shared`, что и сайт.

## Что есть в каркасе

| Вкладка | Что делает |
|---|---|
| Каталог | Поиск по номеру ВАЗ в любом формате или по названию → карточка товара с предложениями и аналогами → «В корзину» |
| Гараж | Автомобили покупателя (общий список с кабинетом на сайте) |
| Корзина | Позиции и оформление заказа: самовывоз, оплата при получении |
| Профиль | Вход и регистрация, история заказов, выход |

Токен покупателя хранится в Keychain / Keystore (`expo-secure-store`).

## Запуск

1. Поднимите бэкенд (`php artisan serve --host=0.0.0.0 --port=8000` в `backend/`).
2. Укажите адрес API, доступный с телефона:

   ```bash
   cp .env.example .env
   ```

   В `.env` впишите IP компьютера в локальной сети, например `EXPO_PUBLIC_API_URL=http://192.168.1.10:8000/api/v1`. Для эмулятора Android используйте `10.0.2.2`.
3. Запустите из корня репозитория:

   ```bash
   pnpm dev:mobile
   ```

   и отсканируйте QR-код приложением Expo Go.
